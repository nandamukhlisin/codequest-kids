## 3. Prompt Audit & Optimasi

**Tujuan:** Mengevaluasi kualitas kode, keamanan, performa, dan kesesuaian fitur.

**Tanggal Penggunaan:** [Rabu, 14 Oktober 2026]


**Platform AI:** [Antigravity IDE]

**Prompt Asli:**
> [Bertindak sebagai Senior Full-Stack Developer. Audit proyek CodeQuest Kids sebelum melakukan perubahan kode.

Periksa:
- Dokumen PRD `.md`.
- Seluruh gambar referensi desain di folder `design/`.
- File SQL di folder `database/`.
- Struktur folder dan seluruh kode yang sudah ada.
- Ketentuan lomba yang tersedia di proyek.

Tugas:
1. Identifikasi struktur proyek dan teknologi yang digunakan.
2. Baca PRD dan pahami seluruh fitur yang dibutuhkan.
3. Periksa database, tabel, kolom, primary key, foreign key, dan relasinya.
4. Petakan screenshot desain dengan halaman dan state yang perlu dibuat.
5. Identifikasi bagian yang sudah selesai, belum dibuat, atau bermasalah.
6. Buat rencana implementasi berdasarkan prioritas deadline.

Jangan menghapus atau menimpa file. Jangan mengubah skema database sebelum memeriksa SQL yang ada. Jangan membuat ulang proyek dari nol jika kode yang tersedia masih bisa digunakan.

Setelah audit, berikan laporan ringkas dan daftar pekerjaan yang harus dilakukan. Lanjutkan pengerjaan hanya setelah struktur proyek dan rencana implementasi jelas.]

**Temuan AI:**
[✅ PRD sangat detail (1431 baris)
 ✅ Database schema lengkap (7 tabel, FK, indexes, seed data)
 ✅ Design system terdokumentasi (DESIGN.md — warna, tipografi, spacing,   komponen)
 ✅ 16 screenshot referensi desain berkualitas tinggi.]

**Perbaikan yang Diterapkan:**
[Tidak ada yang perlu diperbaiki, karena hanya Audit sederhana.]

**Hasil Pengujian:**
[AI menghasilkan audit yang sesuai dengan workspace saya.]
