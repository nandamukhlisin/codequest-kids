# PRD — CodeQuest Kids

## 1. Product Overview

### Product Name
CodeQuest Kids

### Product Type
Interactive Web-Based Coding Education Platform for Elementary School Students

### Competition Theme
Innovating Education Through Technology

### Competition Subtheme
Web Education for Kids (SD)

### Product Concept

CodeQuest Kids adalah platform pembelajaran coding interaktif untuk anak Sekolah Dasar yang mengubah konsep pemrograman dasar menjadi permainan berbasis misi.

Anak tidak langsung belajar syntax pemrograman yang kompleks. Mereka terlebih dahulu belajar computational thinking melalui puzzle visual, perintah sederhana, animasi karakter, tantangan logika, sistem XP, badge, dan progression system.

Tujuan utama produk adalah membuat anak merasa sedang bermain dan memecahkan masalah, tetapi pada saat yang sama mereka sedang mempelajari konsep dasar pemrograman.

---

# 2. Problem Statement

Pembelajaran coding untuk anak SD sering terasa terlalu teknis dan abstrak.

Beberapa masalah yang ingin diselesaikan:

1. Anak belum terbiasa dengan konsep logika pemrograman.
2. Syntax coding dapat terasa sulit bagi pemula.
3. Materi pembelajaran konvensional cenderung kurang interaktif.
4. Anak membutuhkan feedback langsung ketika berhasil atau melakukan kesalahan.
5. Anak membutuhkan motivasi untuk terus belajar.
6. Progress belajar perlu ditampilkan secara sederhana dan mudah dipahami anak.

CodeQuest Kids mengatasi masalah tersebut dengan mengubah proses belajar menjadi pengalaman interaktif berbasis permainan.

---

# 3. Product Goals

## Primary Goals

1. Mengenalkan computational thinking kepada anak SD.
2. Mengajarkan konsep dasar coding secara bertahap.
3. Membuat proses belajar coding terasa menyenangkan.
4. Memberikan feedback langsung terhadap jawaban anak.
5. Menyimpan progress pembelajaran anak.

2. Membantu anak terbiasa memecahkan masalah secara sistematis.

2. Anak diberikan sebuah misi.

# 8. Learning Curriculum

## Level 1 — Coding Explorer

Topic:
Introduction to Computational Thinking

Materi:
- Apa itu coding?
- Coding sebagai kumpulan instruksi.
- Mengikuti langkah secara berurutan.

Challenge:
Menggerakkan karakter menuju tujuan.

---

## Level 2 — Sequence

Topic:
Urutan Perintah

Concept:
Program menjalankan instruksi berdasarkan urutan.

Example commands:

FORWARD
LEFT
RIGHT
JUMP

Challenge:
Menyusun command agar karakter mencapai tujuan.

---

## Level 3 — Loop

Topic:
Perulangan

Concept:
Melakukan instruksi yang sama beberapa kali.

Example:

REPEAT 3 TIMES
    FORWARD

Challenge:
Menyelesaikan jalur dengan menggunakan repeat.

---

## Level 4 — Condition

Topic:
Percabangan

Concept:
Program dapat mengambil keputusan berdasarkan kondisi.

Example:

IF PATH IS BLOCKED
    TURN RIGHT

Challenge:
Membantu karakter melewati kondisi yang berbeda.

---

## Level 5 — Variable

Topic:
Variabel sederhana

Concept:
Variabel digunakan untuk menyimpan sebuah nilai.

Example:

COINS = 5

Challenge:
Menggunakan nilai untuk menyelesaikan misi.

---

## Level 6 — Mini Project

Topic:
Applying Coding Concepts

Anak menggunakan konsep yang telah dipelajari untuk membuat mini project sederhana.

Contoh:

- Character movement
- Simple maze
- Collect the stars
- Simple animation

The main coding challenges use a grid-based environment.

- Player character.
- Goal.

- Collectible stars.
- Grid cells.

- LEFT

- JUMP

- IF

Optional objectives:

- Collect all required stars.
- Use a specific coding concept.
- Complete the challenge within a command limit.
- Complete the challenge efficiently.

## Failure

A challenge may fail when:

- The player hits an obstacle.
- Commands end before reaching the goal.
- An invalid action is performed.

Students must be able to:

- Read feedback.
- Request hints.
- Reset the challenge.
- Try again.

## 45. Database Relationships

CodeQuest Kids menggunakan database relasional dengan hubungan antar tabel sebagai berikut:

```text
USERS
  │
  ├──────────────< PROGRESS >────────────── LEVELS
  │                                          │
  │                                          └──────────────< CHALLENGES
  │
  └──────────────< USER_BADGES >──────────── BADGES


RELATIONSHIP:
- users 1 : N progress
- levels 1 : N progress
- levels 1 : N challenges
- users 1 : N user_badges
- badges 1 : N user_badges


FOREIGN KEY:
- progress.user_id      → users.id
- progress.level_id     → levels.id
- challenges.level_id   → levels.id
- user_badges.user_id   → users.id
- user_badges.badge_id  → badges.id


TABLE RELATIONSHIP DETAILS:

1. users → progress
   - Satu user dapat memiliki banyak data progress.
   - Setiap data progress dimiliki oleh satu user.

2. levels → progress
   - Satu level dapat memiliki progress dari banyak user.
   - Setiap data progress mengacu pada satu level.

3. levels → challenges
   - Satu level dapat memiliki banyak challenge.
   - Setiap challenge berada di dalam satu level.

4. users → user_badges
   - Satu user dapat memperoleh banyak badge.
   - Setiap data user_badges dimiliki oleh satu user.
```
